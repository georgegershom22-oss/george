# Materials Metadata

This dataset uses representative material properties for common battery tab and busbar alloys. Values are approximate and intended to produce physically plausible trends, not to represent any specific supplier grade.

Columns:
- `thermal_conductivity_W_mK`
- `specific_heat_J_kgK`
- `density_kg_m3`
- `melting_point_C`
- `cte_1e6_per_K`
- `electrical_resistivity_uOhm_m`
- `laser_absorptivity_1`
- `ultrasonic_absorption_factor`
- `default_tab_thickness_um`
