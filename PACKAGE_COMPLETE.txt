================================================================================
SIMULATION SPECIFICATIONS
================================================================================

Physics:
- Linear acoustics (Helmholtz equation)
- Three-layer ocean stratification
- Plane wave excitation
- Non-reflecting boundaries
- Steady-state harmonic analysis

Domain:
- Size: 100m × 50m (2D waveguide)
- Layers: Surface (0-15m), Thermocline (15-35m), Deep (35-50m)
- Probes: x=20m (inlet), x=80m (outlet)
- Spacing: Δx=60m between probes

Materials (Ocean Thermocline):
┌─────────┬────────┬──────────┬──────────┬──────────┐
│ Layer   │ Depth  │ ρ (kg/m³)│ K (GPa)  │ c (m/s)  │
├─────────┼────────┼──────────┼──────────┼──────────┤
│ Surface │ 0-15m  │ 1023     │ 2.364    │ 1520     │
│ Thermo  │ 15-35m │ 1026     │ 2.278    │ 1490     │
│ Deep    │ 35-50m │ 1028     │ 2.221    │ 1470     │
└─────────┴────────┴──────────┴──────────┴──────────┘

Frequency:
- Range: 100-5000 Hz
- Increment: 50 Hz (complete file) / 25 Hz (full file)
- Points: 99 (complete) / 197 (full)

================================================================================
CUSTOMIZATION
================================================================================

Change Frequency Range:
  Edit .inp: *STEADY STATE DYNAMICS, DIRECT
              <start>, <end>, <n_points-1>

Modify Stratification:
  Edit materials: *MATERIAL, NAME=WATER_THERMOCLINE
                  *DENSITY / *BULK MODULUS

Generate New Mesh:
  python mesh_generator.py --length 100 --depth 50 --size 0.2

================================================================================
TROUBLESHOOTING
================================================================================

Job Won't Start:
→ Check: cat acoustic_TL.dat | tail -50
→ Verify: Abaqus in PATH

No Output Created:
→ Check: tail -f acoustic_TL.sta
→ Review: acoustic_TL.msg for errors

Post-Processing Fails:
→ Verify: Node sets PROBE_IN, PROBE_OUT exist
→ Check: ODB file not corrupted

Plotting Fails:
→ Install: pip install matplotlib numpy scipy
→ Alternative: View CSV in Excel
