QUALITATIVE DATA CODEBOOK AND THEMATIC ANALYSIS GUIDE
=======================================================

Research Topic: Leveraging Machine Learning to Examine Innovation Adoption and Constraints 
            in Nigerian SMEs: Implications for Performance and Growth

Data Collection Period: August-September 2024
Total Interviews: 25 semi-structured interviews
Total Focus Groups: 5 FGDs (39 total participants)
Geographic Coverage: 12 states across Nigeria

---

PART 1: CODING FRAMEWORK
==========================

This codebook provides a systematic framework for analyzing the qualitative data collected.
Codes are organized hierarchically into themes, sub-themes, and specific codes.

---

THEME 1: INNOVATION ADOPTION DRIVERS
======================================

Definition: Factors, circumstances, or motivations that led SMEs to adopt technological innovations

SUB-THEME 1.1: Crisis-Driven Adoption
Code: CRISIS_CATALYST
Definition: Innovation adoption triggered by specific business crisis or failure
Examples: 
- Server crash leading to cloud adoption (INT-001)
- Pest outbreak leading to IoT sensors (INT-002)  
- Disease outbreak in poultry (INT-009)
Indicators: "After we lost...", "When X failed...", "The crisis forced us..."

Code: CLIMATE_PRESSURE
Definition: Climate change impacts driving technology adoption
Examples:
- Erratic rainfall patterns (INT-005)
- Extreme weather events (FGD-02)
Indicators: "Rainfall patterns changed...", "Climate is unpredictable..."

SUB-THEME 1.2: Market-Driven Adoption  
Code: COMPETITIVE_PRESSURE
Definition: Adoption to compete with other businesses (domestic or international)
Examples:
- Competing with Chinese textiles (INT-003)
- Competing with imported rice (FGD-02)
Indicators: "We were losing market share...", "Chinese/Indian competitors..."

Code: CLIENT_DEMAND
Definition: Customer or client requirements driving adoption
Examples:
- ISO certification requirements (FGD-03)
- Supermarket quality standards (INT-009)
Indicators: "Client required...", "Market demanded...", "To supply to X we needed..."

Code: MARKET_EXPANSION
Definition: Adopting technology to access new markets
Examples:
- Export opportunities through traceability (INT-002)
- Online sales expanding geographic reach (FGD-04)
Indicators: "Open new markets...", "Reach customers in...", "Export to..."

SUB-THEME 1.3: Vision-Driven Adoption
Code: MISSION_ORIENTED
Definition: Innovation driven by social mission or personal values
Examples:
- Healthcare access mission (INT-008)
- Environmental mission in waste management (INT-025)
Indicators: "My vision was...", "I wanted to solve...", "Impact on society..."

Code: MODERNIZATION_DESIRE
Definition: Desire to modernize "traditional" business
Examples:
- Young generation wanting to modernize family farm (INT-005)
- Making farming "modern" and attractive (INT-002)
Indicators: "Do things differently...", "Modern approach...", "21st century business..."

SUB-THEME 1.4: Efficiency-Driven Adoption
Code: COST_REDUCTION
Definition: Adopting technology primarily to reduce costs
Examples:
- Cloud reducing infrastructure costs (INT-001)
- Automation reducing labor costs (INT-003)
Indicators: "Save money on...", "Reduce costs...", "More economical..."

Code: PRODUCTIVITY_IMPROVEMENT  
Definition: Adopting technology to increase output or speed
Examples:
- Automated looms increasing production 6x (INT-003)

PART 2: ANALYTICAL PROCEDURES
==============================

Step 1: Data Familiarization
- Read all transcripts thoroughly
- Note initial impressions and patterns
- Create memo of emerging themes

Step 2: Initial Coding
- Apply codes systematically to each transcript
- Use NVivo, Atlas.ti, or manual coding
- Code each meaning unit (sentence, paragraph, or exchange)
- Multiple codes can apply to same text segment

Step 3: Code Refinement
- Review coded segments for consistency
- Merge redundant codes
- Split overly broad codes
- Refine code definitions

Step 4: Thematic Analysis
- Group codes into themes
- Identify relationships between themes
- Create thematic maps/diagrams
- Look for patterns within and across cases

Step 5: Cross-Case Analysis
- Compare patterns across sectors
- Compare by geographic location
- Compare by innovation level (high/medium/low)
- Compare by gender

Step 6: Quantification of Qualitative Data
For ML integration, quantify themes:
- Count frequency of codes per case
- Create binary variables (theme present=1, absent=0)
- Rate intensity of themes (0-3 scale: absent, minor, moderate, major)
- Create composite scores for theme clusters

Example Quantification:
Participant | CAPITAL_CONSTRAINT | POWER_UNRELIABILITY | REVENUE_GROWTH | Sector | InnovationLevel
INT-001     | 2 (moderate)       | 3 (major)          | 3 (major)      | Tech   | High
INT-002     | 3 (major)          | 2 (moderate)       | 3 (major)      | Agric  | High
...

Step 7: Integration with Quantitative Data
- Link qualitative themes to survey variables
- Use qualitative findings to explain ML model results
- Identify mechanisms behind statistical correlations
- Generate hypotheses for further testing

PART 3: QUALITY ASSURANCE
==========================

Inter-Coder Reliability:
- Have 2-3 coders independently code 20% of transcripts
- Calculate Cohen's Kappa or percentage agreement
- Discuss discrepancies and refine codebook
- Target: >80% agreement or Kappa >0.70

Member Checking:
- Share analysis summaries with select participants
- Verify interpretations match their experiences
- Incorporate feedback

Triangulation:
- Compare interview and FGD data
- Look for convergence and divergence
- Cross-validate with secondary sources

Reflexivity:
- Document researcher positionality
- Note potential biases
- Transparent about interpretation process

PART 4: REPORTING GUIDELINES
=============================

Quotation Selection:
- Choose vivid, representative quotes
- Include participant ID and context
- Balance across participants (don't over-rely on few voices)
- Include counter-examples and deviant cases

Reporting Structure:
1. Overview of participants and data collection
2. Major themes with sub-themes
3. Quotes and examples supporting each theme
4. Cross-cutting patterns (sector, geography, gender)
5. Integration with quantitative findings
6. Implications for theory and practice

Visualization:
- Thematic maps showing relationships
- Word clouds for frequency
- Network diagrams for co-occurrence
- Comparison charts (e.g., barriers by sector)

PART 5: MACHINE LEARNING INTEGRATION GUIDE
===========================================

Converting Qualitative Data for ML Analysis:

1. Document-Term Matrix
- Create bag-of-words representation
- Use TF-IDF weighting
- Can be input to clustering, classification, topic modeling

2. Theme Presence Matrix
- Binary indicators for each code/theme
- Example: Does this participant mention CAPITAL_CONSTRAINT? (Yes=1, No=0)
- Can be merged with survey data for integrated analysis

3. Theme Intensity Matrix
- Ordinal scale (0-3) for theme prominence
- More nuanced than binary
- Suitable for regression analysis

4. Sentiment and Emotion Coding
- Code emotional tone of statements
- Frustration, hope, fear, pride, etc.
- Can reveal affective dimensions of innovation adoption

5. Network Analysis
- Co-occurrence of codes
- Which barriers and enablers appear together?
- Network centrality = importance

Example Applications:

Supervised Learning:
- Use qualitative codes as features to predict innovation success
- Compare with survey-based features
- Feature importance reveals key factors

Unsupervised Learning:
- Cluster participants based on qualitative themes
- Do clusters match predefined categories (sector, innovation level)?
- Topic modeling to discover latent themes

Natural Language Processing:
- Named Entity Recognition: Organizations, technologies, locations mentioned
- Sentiment analysis: Overall tone of innovation narratives
- Keyword extraction: Most important terms by sector

Mixed Methods ML:
- Combine survey variables + qualitative theme variables
- Richer predictive models
- Qualitative themes explain "why" behind statistical patterns
