# SOFC Technical & Technological Dataset\n\nThis dataset supports the study: Harnessing Domestic Gas for Power: A Techno-Economic and Socio-Political Analysis of Solid Oxide Fuel Cells (SOFCs) in Mitigating Nigeria's Electricity Crisis.\n\n- data/raw: downloaded reports, PDFs, web archives\n- data/sources: source registry and metadata\n- data/interim: parsed and normalized intermediates\n- data/processed: final clean datasets (CSV)\n- scripts: tools for download and dataset generation\n
