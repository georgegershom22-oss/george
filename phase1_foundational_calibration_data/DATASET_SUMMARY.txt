4. APPLICATION GUIDE
================================================================================

FOR FEM CALIBRATION:
-------------------
→ Use: material_properties/*.csv
→ Apply: Temperature-dependent constitutive models
→ Validate: Against process_window_data/sintering_profile_experiments.csv

Key equations:
  - Viscoplastic sintering model
  - Thermal expansion mismatch
  - Densification kinetics

FOR PHASE-FIELD MODELING:
-------------------------
→ Use: microstructural_evolution/*.csv
→ Calibrate: Grain growth, pore evolution kinetics
→ Validate: Match pore size distributions and morphology

Key parameters:
  - Grain boundary mobility
  - Surface diffusion coefficients
  - Interfacial energies

FOR REINFORCEMENT LEARNING:
---------------------------
→ State space: Density, temperature, time, microstructure
→ Action space: action_space_boundaries.csv
→ Reward function: Based on final_density, warpage, cracking

Training data:
  - Initial episodes: sintering_profile_experiments.csv
  - State transitions: Combine kinetics + microstructure data
  - Terminal rewards: Density (↑), Warpage (↓), No cracking

Action boundaries:
  Heating rate:     1-15°C/min (optimal: 3-7)
  Peak temperature: 1150-1550°C (material-dependent)
  Hold time:        30-480 min (optimal: 90-240)
  Cooling rate:     2-15°C/min (optimal: 3-8)
