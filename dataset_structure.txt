================================================================================
DATASET RELATIONSHIPS & MERGE KEYS
================================================================================

PRIMARY KEY: Year (all datasets)
SECONDARY KEYS:
  • Region (barriers, regional summary, broadband)
  • State (broadband only)

MERGE SCENARIOS
---------------

1. NATIONAL TIME SERIES ANALYSIS
   Merge: macro + sectors + tech + sme + policy
   Key: Year
   Result: 10 observations, 80+ variables

2. REGIONAL PANEL ANALYSIS
   Merge: regional + barriers
   Key: Year + Region
   Result: 60 observations, 30+ variables
   Enhancement: Add macro + tech by Year

3. STATE-LEVEL INFRASTRUCTURE ANALYSIS
   Merge: broadband (grouped by region) + regional + barriers
   Key: Year + Region
   Result: 60 observations, 40+ variables

4. COMPREHENSIVE MERGED DATASET
   Merge: regional + barriers + (macro + tech + sme + policy)
   Keys: Year + Region (regional), Year (national)
   Result: 60 regional observations with national context

5. SECTORAL-REGIONAL ANALYSIS
   Merge: sectors + regional (cross join on year)
   Key: Year
   Result: 60 region-year observations + sectoral variables

================================================================================
FEATURE ENGINEERING SUGGESTIONS
================================================================================

TEMPORAL FEATURES
-----------------
• Lag variables (t-1, t-2) for predictors
• Growth rates (year-over-year % change)
• Moving averages (3-year, 5-year)
• Cumulative sums (e.g., total CBN interventions)
• Time trend (linear: 0, 1, 2, ..., 9)
• Year dummies (for non-parametric time effects)

SPATIAL FEATURES
----------------
• Region dummies (South West, South East, etc.)
• North vs South indicator (development divide)
• Distance to Lagos (economic center proxy)
• Neighboring region effects (spatial lag)

INTERACTION FEATURES
--------------------
• Infrastructure × Policy (complementarity)
• Broadband × ICT sector growth (synergy)
• Finance access × Innovation (enabling effect)
• Corruption × Government budget (governance quality)

COMPOSITE INDICES
-----------------
• Weighted barrier index (PCA of 15 barriers)
• Digital readiness index (broadband + mobile + internet)
• Policy support index (budget + training + schemes)
• Ecosystem maturity score (hubs + VC + R&D + patents)

RATIO FEATURES
--------------
• SME density per capita
• VC investment per SME
• Government budget per SME
• Hubs per 1M population
• Credit-to-GDP ratio (already included)

CATEGORICAL ENCODINGS
---------------------
• Region → one-hot encoding (6 dummies)
• State → one-hot encoding (10 dummies)
• Year → cyclical encoding (for periodicities)
• Sector → one-hot encoding (for sectoral models)

PYTHON CODE: COMPREHENSIVE MERGE EXAMPLE
================================================================================

import pandas as pd

# Load all datasets
macro = pd.read_csv('macroeconomic_indicators.csv')
sectors = pd.read_csv('sectoral_growth_rates.csv')
tech = pd.read_csv('technology_adoption_indices.csv')
sme = pd.read_csv('sme_landscape_indicators.csv')
barriers = pd.read_csv('innovation_adoption_barriers.csv')
regional = pd.read_csv('regional_summary_statistics.csv')
broadband = pd.read_csv('broadband_penetration_by_state.csv')
policy = pd.read_csv('policy_and_external_factors.csv')

# Strategy A: Full regional panel with national context
national = (macro
    .merge(sectors, on='Year', suffixes=('', '_sector'))
    .merge(tech, on='Year', suffixes=('', '_tech'))
    .merge(sme, on='Year', suffixes=('', '_sme'))
    .merge(policy, on='Year', suffixes=('', '_policy'))
)

full_panel = (regional
    .merge(barriers, on=['Year', 'Region'], suffixes=('', '_barrier'))
    .merge(national, on='Year')
)

print(f"Full panel shape: {full_panel.shape}")
print(f"Variables: {full_panel.columns.tolist()}")

# Strategy B: State-level with regional aggregation
broadband_agg = (broadband
    .groupby(['Region', 'Year'])
    .agg({
        'Broadband_Penetration_Percent': 'mean',
        'Mobile_Penetration_Percent': 'mean',
        'Internet_Users_Percent': 'mean',
        'Electricity_Access_Percent': 'mean',
        'Population_Million': 'sum'
    })
    .reset_index()
)

regional_full = (regional
    .merge(barriers, on=['Year', 'Region'])
    .merge(broadband_agg, on=['Year', 'Region'])
    .merge(national, on='Year')
)

print(f"Regional full shape: {regional_full.shape}")

# Export for ML
regional_full.to_csv('merged_ml_ready.csv', index=False)
print("✓ Exported: merged_ml_ready.csv")

R CODE: COMPREHENSIVE MERGE EXAMPLE
================================================================================

library(tidyverse)

# Load all datasets
macro <- read_csv('macroeconomic_indicators.csv')
sectors <- read_csv('sectoral_growth_rates.csv')
tech <- read_csv('technology_adoption_indices.csv')
sme <- read_csv('sme_landscape_indicators.csv')
barriers <- read_csv('innovation_adoption_barriers.csv')
regional <- read_csv('regional_summary_statistics.csv')
broadband <- read_csv('broadband_penetration_by_state.csv')
policy <- read_csv('policy_and_external_factors.csv')

# National-level merge
national <- macro %>%
  left_join(sectors, by = "Year") %>%
  left_join(tech, by = "Year") %>%
  left_join(sme, by = "Year") %>%
  left_join(policy, by = "Year")

# Regional panel merge
full_panel <- regional %>%
  left_join(barriers, by = c("Year", "Region")) %>%
  left_join(national, by = "Year")

glimpse(full_panel)

# Export
write_csv(full_panel, "merged_ml_ready.csv")
